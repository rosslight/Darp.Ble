# Project

Project-level links and status for Darp.Ble.

## Status

Darp.Ble is under active development. Expect API changes while the platform backends and BLE role coverage continue to evolve.

## Packages

| Package | Purpose |
| --- | --- |
| [`Darp.Ble`](https://www.nuget.org/packages/Darp.Ble) | Core abstractions and shared BLE API. |
| [`Darp.Ble.WinRT`](https://www.nuget.org/packages/Darp.Ble.WinRT) | Windows backend using WinRT Bluetooth APIs. |
| [`Darp.Ble.Android`](https://www.nuget.org/packages/Darp.Ble.Android) | Android backend using the Android Bluetooth stack. |
| [`Darp.Ble.HciHost`](https://www.nuget.org/packages/Darp.Ble.HciHost) | HCI host backend for BLE adapters and custom transports. |
| [`Darp.Ble.Mock`](https://www.nuget.org/packages/Darp.Ble.Mock) | Local testing backend without BLE hardware. |
